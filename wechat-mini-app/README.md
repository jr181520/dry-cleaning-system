## 🛠️ 微信开发者工具配置

### 1. 下载安装
- 前往 [微信公众平台](https://mp.weixin.qq.com/) 下载微信开发者工具
- 安装并登录您的微信账号

### 2. 导入项目
1. 打开微信开发者工具
2. 点击"导入项目"
3. 项目目录选择：`dry_cleaning_system/wechat-mini-app`
4. AppID：输入您的小程序AppID（如果没有可以先使用测试号）
5. 项目名称：`干洗店小程序`

### 3. 配置服务器域名
在微信开发者工具中：
1. 点击右上角"详情"
2. 选择"本地设置"
3. 勾选"不校验合法域名"（开发阶段）

或者在 [微信公众平台](https://mp.weixin.qq.com/) 后台：
1. 进入"开发管理"
2. 选择"开发设置"
3. 在"服务器域名"中添加：
   - request合法域名：`http://localhost:3000`
   - socket合法域名：`ws://localhost:3000`

### 4. 开启调试
- 开启"开发者工具"中的"调试器"
- 使用"模拟器"进行页面预览
- 使用"真机调试"进行手机测试

## 📋 登录流程说明

### 微信一键登录
1. 用户点击"微信一键登录"按钮
2. 调用 `wx.login()` 获取登录凭证（code）
3. 调用 `wx.getUserProfile()` 获取用户信息
4. 将code和用户信息发送到后端服务器
5. 后端验证并返回token和用户信息
6. 保存用户信息到全局数据

### 手机号登录
1. 用户输入手机号
2. 点击"获取验证码"
3. 后端发送验证码到手机
4. 用户输入验证码和密码
5. 验证通过后返回token和用户信息

## 🚀 启动后端服务

```bash
cd api
node server.js
```

后端服务将运行在 `http://localhost:3000`

## 📱 测试账号

开发阶段可以使用以下测试功能：

### 模拟数据
- 手机号：输入任意符合格式的手机号（如 13800138000）
- 验证码：任意6位数字（系统会返回成功）
- 微信登录：会自动获取code并模拟登录

### 取件码
- 以"P"开头的取件码会被验证成功
- 例如：P1234567890

## ⚙️ 配置修改

### 修改API地址
编辑 `app.js` 中的 `globalData.apiBaseUrl`：
```javascript
globalData: {
  apiBaseUrl: 'https://your-api-domain.com/api',
}
```

### 修改小程序名称
编辑 `app.json` 中的 `navigationBarTitleText`：
```json
{
  "window": {
    "navigationBarTitleText": "您的店铺名称"
  }
}
```

### 添加新页面
1. 在 `pages/` 目录下创建页面文件夹
2. 添加 `index.js`, `index.wxml`, `index.wxss` 文件
3. 在 `app.json` 的 `pages` 数组中添加页面路径

## 🎯 常见问题

### 1. 登录失败
- 检查是否在开发阶段勾选了"不校验合法域名"
- 检查手机号格式是否正确
- 查看控制台错误信息

### 2. 无法获取用户信息
- 确保用户已授权获取昵称和头像
- 检查 `getUserProfile` 的调用是否正确

### 3. 页面空白
- 检查页面路径是否正确
- 查看控制台是否有JS错误
- 确认所有页面文件都已创建

### 4. 扫码功能无法使用
- 模拟器不支持真实扫码
- 需要在真机上测试
- 确保camera权限已申请
