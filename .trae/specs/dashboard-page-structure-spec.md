# 总后台系统页面结构规格

## 1. 功能需求

### 1.1 核心要求
- **首页只展示仪表盘**：系统首页（总仪表盘）只显示仪表盘内容，其他功能内容不显示
- **侧边栏导航**：所有其他功能内容划入侧边栏的下级页面展示
- **避免页面重叠**：确保不会出现两个页面同时显示的情况
- **导航功能**：侧边栏菜单项点击后能正确切换到对应内容

## 2. 实现方案

### 2.1 页面结构
- **首页**：`#dashboard-content` 内容区域，默认显示
- **其他功能**：所有其他内容区域默认隐藏（添加 `hidden` 类）
- **侧边栏**：包含分级菜单，支持展开/收起子菜单

### 2.2 导航逻辑
- **点击菜单项**：隐藏所有内容区域，显示对应目标区域
- **父菜单项**：点击展开/收起子菜单，不切换内容区域
- **子菜单项**：点击切换到对应内容区域
- **URL锚点**：支持通过URL锚点直接访问对应内容

### 2.3 技术实现
- **内容区域管理**：使用 `content-section` 类标识所有内容区域
- **隐藏状态**：使用 `hidden` 类控制内容区域的显示/隐藏
- **导航处理**：`initNavigation()` 函数处理导航链接点击事件
- **分级菜单**：`initSubmenuFunctionality()` 函数处理子菜单展开/收起
