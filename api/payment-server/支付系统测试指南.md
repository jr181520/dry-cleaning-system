# 支付系统测试指南

## 🚀 快速启动

### 1. 启动支付服务器

打开 PowerShell，运行：

```powershell
cd "d:\Trae CN\bin\dry_cleaning_system\api\payment-server"
node server.js
```

如果看到以下输出，说明服务器启动成功：
```
========================================
  支付网关服务器已启动
  端口: http://localhost:3002
========================================
```

**注意：保持这个窗口不要关闭！**

---

## 🧪 测试入口

### M端 - POS收银系统（手机/平板）

在浏览器中打开：
```
http://localhost:3002/m-pos.html
```

**测试步骤：**

1. **添加商品** → 点击商品按钮添加干洗项目
2. **现金支付** → 输入金额，点击"💵 现金收款"
3. **扫码支付** → 点击"📱 扫码收款"（扫描用户付款码）
4. **会员卡支付** → 输入会员卡号，点击"💳 会员卡支付"

---

### C端 - 支付页面（顾客用）

在浏览器中打开：
```
http://localhost:3002/c-payment.html
```

**或者带订单号访问：**
```
http://localhost:3002/c-payment.html?orderId=你的订单号
```

**测试步骤：**

1. **创建测试订单** → 在 M端创建订单，获得订单号
2. **选择支付方式**：
   - 💵 现金支付
   - 💳 会员卡支付
   - 📱 微信/支付宝扫码
3. **完成支付** → 根据选择的支付方式完成付款

---

### C端 - 充值页面（顾客用）

在浏览器中打开：
```
http://localhost:3002/c-recharge.html
```

**测试步骤：**

1. **输入会员卡号** → 输入已有的会员卡号（如 MC001）
2. **选择充值金额** → 点击 500/1000/2000 元按钮
3. **确认充值** → 完成充值（现金充值）

## 🔍 常见问题

### Q1: 浏览器无法连接 localhost:3002
**原因：** 支付服务器未启动

**解决方法：**
1. 打开新的 PowerShell 窗口
2. 运行：
```powershell
cd "d:\Trae CN\bin\dry_cleaning_system\api\payment-server"
node server.js
```

---

### Q2: 页面显示"无法连接服务器"
**原因：** 跨域问题或服务器未响应

**解决方法：**
1. 检查支付服务器是否显示"支付网关服务器已启动"
2. 尝试访问 http://localhost:3002/api/health 查看是否正常
3. 刷新浏览器页面

---

### Q3: 会员卡无法使用
**原因：** 会员卡不存在或余额不足

**解决方法：**
1. 先在充值页面充值
2. 或使用测试卡号：MC001（密码：123456）

---

### Q4: 端口被占用
**错误：** `EADDRINUSE: address already in use :::3002`

**解决方法：**
1. 关闭占用端口的进程：
```powershell
netstat -ano | findstr ":3002"
taskkill /PID <进程ID> /F
```

2. 或者直接重启服务器
