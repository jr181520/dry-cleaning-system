```bash

# 查看用户余额

  -H "Content-Type: application/json" \
  -d '{"orderId":"TEST001","amount":99,"paymentMethod":"wechat"}'

# 创建余额支付
curl -X POST http://localhost:3002/api/payment/create \
  -H "Content-Type: application/json" \
  -d '{"orderId":"TEST002","amount":50,"paymentMethod":"balance","userId":"test_user_001"}'

# 门店结算查询
curl http://localhost:3002/api/settlement/store/test_store_001

# 门店提现
curl -X POST http://localhost:3002/api/settlement/store/test_store_001/withdraw \
  -H "Content-Type: application/json" \
  -d '{"amount":100,"bankAccount":"6222021234567890"}'
```

## ❌ 常见问题

### 问题1: 端口被占用

```
Error: listen EADDRINUSE :::3002
```

**解决方案**:
```bash
# Windows
netstat -ano | findstr :3002
taskkill /PID <进程ID> /F

# 或使用其他端口
# 修改 test-server.js 中的 PORT
```

### 问题2: npm install 失败

**解决方案**:
```bash
# 清理缓存
npm cache clean --force

# 重新安装
rm -rf node_modules
npm install
```

### 问题3: 测试连接失败

```
Error: connect ECONNREFUSED localhost:3002
```

**解决方案**:
1. 确保测试服务器已启动
2. 检查防火墙设置
3. 等待服务器完全启动（3-5秒）
