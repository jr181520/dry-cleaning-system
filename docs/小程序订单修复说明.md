# 微信小程序订单功能修复说明

## 修复时间
2026-05-19

## 问题描述
小程序端无法创建订单，主要表现为：
- 点击确认支付后没有响应
- 订单创建接口调用失败
- 用户未正确登录导致 userId 为空

## 修复内容

### 1. 登录逻辑改进 (app.js)

**改进点：**
- 添加本地存储恢复机制：启动时检查并恢复登录状态
- 添加模拟登录后备方案：API调用失败时自动使用模拟登录
- 更好的错误处理：捕获所有失败情况并给出友好提示

**新增函数：**
- `mockLogin()`: 模拟登录函数，用于开发和测试

**修改函数：**
- `login()`: 
  - 先检查本地缓存是否有登录信息
  - API失败时自动调用 mockLogin()
  - 将用户信息保存到本地存储

### 2. API请求改进 (app.js)

**修改函数：**
- `request()`:
  - 添加 15 秒超时设置
  - 添加 Token 过期处理（401响应）
  - 更好的错误消息提示

### 3. 订单创建改进 (payment/index.js)

**修改函数：**
- `createOrder()`:
  - 添加用户登录检查
  - 添加订单数据检查
  - 添加详细的日志输出

## 测试步骤

### 1. 测试登录功能
1. 打开小程序开发者工具
2. 清除缓存并重新编译
3. 查看控制台日志：
   - 应该显示 `[登录] 微信登录成功，code: xxx`
   - 或者 `[登录] 模拟登录完成，openid: oMini_xxx`

### 2. 测试订单创建
1. 选择服务 -> 选择门店 -> 选择配送方式 -> 确认订单
2. 在支付页面点击"确认支付"
3. 查看控制台日志：
   - 应该显示 `[创建订单] 用户ID: oMini_xxx`
   - 应该显示 `[创建订单] 提交数据: {...}`
   - 应该显示 `[创建订单] 成功`

### 3. 使用诊断工具
1. 打开 `小程序订单API诊断.html`
2. 点击"运行测试"
3. 查看测试结果

## API配置说明

小程序使用的API地址在 `app.js` 中配置：
```javascript
globalData: {
  apiBaseUrl: 'http://192.168.1.8:3000/api',  // 需要改为实际的服务器地址
}
```

**注意：**
- 开发阶段：在微信开发者工具中勾选"不校验合法域名"
- 生产阶段：需要配置 HTTPS 域名
