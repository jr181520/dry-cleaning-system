# 微信小程序订单功能说明

## 功能概述

微信小程序已完成与C端H5一致的订单功能开发，包括：
- 门店自提方案（用户自行送衣到店，享受9折优惠）
- 跑腿取件方案（骑手上门的衣物取送）
- 扫码支付功能（M端代客下单生成的二维码可引流到小程序支付）

## 功能流程

### C端下单流程
```
选择服务 → 选择门店 → 选择取件方式 → 预约时间 → 支付 → 订单完成
```

### M端代客下单引流流程
```
M端代客下单 → 生成小程序码 → 用户扫码 → 进入小程序订单详情 → 微信授权登录 → 完成支付
```

## 已实现功能

### 1. 扫码进入订单详情页
- **入口**: M端生成的微信小程序码
- **参数格式**: `id=订单ID&s=门店ID&a=金额`
- **页面**: `pages/order/detail/index`
- **处理逻辑**: 
  - 自动解析scene参数
  - 显示扫码支付横幅
  - 支持立即支付或稍后支付

### 2. 订单详情页
- 实时订单状态更新（轮询机制）
- 订单进度展示
- 取件码显示（待取件状态）
- 取件方式选择（到店自提/配送到家）
- 配送表单（配送到家时显示）
- 联系门店、导航到店功能
- 催单、评价功能

### 3. 支付页面
- 多种支付方式支持：
  - 微信支付（小程序调起微信支付）
  - 账户余额
  - 模拟支付（开发测试用）
- 支付倒计时
- 支付结果处理

### 4. 支付成功页面
- 订单信息展示
- 配送跟踪（跑腿订单）
- **分享功能**：
  - 生成小程序码分享
  - 保存到相册
  - 转发给好友

### 5. 订单列表页
- 历史订单列表
- 订单状态筛选
- 订单操作（查看详情、取消等）

## API接口

### 生成小程序码
```
POST /api/mini-qr/generate
Content-Type: application/json

{
  "type": "order_pay",    // 类型：order_pay-订单支付, store-门店
  "orderId": "ORD123456",  // 订单ID
  "storeId": "ST001",      // 门店ID
  "amount": 88             // 订单金额
}

响应：
{
  "success": true,
  "data": {
    "imageData": "base64编码的图片数据",
    "contentType": "image/png",
    "scene": "id=ORD123456&s=ST001&a=88"
  }
}
```

### 获取订单状态
```
GET /api/orders/{orderId}/status

响应：
{
  "success": true,
  "data": {
    "orderId": "ORD123456",
    "orderNo": "CL20260517001",
    "status": "pending",
    "items": [...],
    "amounts": {...},
    "storeName": "干洗店",
    ...
  }
}
```

## 配置说明

### 环境变量
需要在后端 `.env` 或系统环境变量中配置：
```
WX_MINI_APP_ID=你的小程序AppID
WX_MINI_APP_SECRET=你的小程序AppSecret
```

### 小程序配置
- 小程序需要在微信公众平台配置：
  - 服务器域名（request合法域名）
  - 小程序码生成权限
  - 微信登录权限

## 注意事项

1. **微信支付**：需要在微信支付商户平台配置Native支付或JSAPI支付
2. **access_token**：后端会自动缓存和刷新
3. **小程序码参数**：scene参数最大32个可见字符，需要精简
4. **支付安全**：生产环境务必启用真实的微信支付验证
